Why Baseline Underpredicts D_eff by ~40%

Routing every path through the 3D body centroid ci (and 2D merged surface centroid) inflates link length by λ ≈ 1.30×. Because half-link volume Vitk = Vi / zi is conserved, area shrinks by 1/λ (Aitk = Vitk / ditk), so conductance Gitk = σVitk / ditk2 drops by 1/λ2 ≈ 0.59×!

How 1-Pass SC Fixes It in a Single Solve

Keeps 100% identical pore volume (Vitk = Vi / zi) and coupled fallback, so constrictivity Ceff = 1/Cc stays locked onto TauFactor. Replaces centroid-detour length ditk with direct throat-to-throat chord d̃itk (interior) and perpendicular plane distance (boundary) before solving.

Result Across All 5 Microstructures

Directly from the single solved potential field:
• Tortuosity τc error vs TF τrec: +30% → +0.4% to +4.0%
• Constrictivity 1/Cc vs TF Ceff: Improved on 4/5 samples
• Solved Deff = 1/F error: −40% → 8.4% mean abs. error
